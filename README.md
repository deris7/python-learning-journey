# Python Learning Journey

Documenting my journey to becoming a software engineer through Python fundamentals, problem-solving, clean code, and progressively challenging projects.

# Week 1

## variabel data types

- Topics covered:
- Printing output using the print() function.
- Understanding variables as containers for storing values in a program.
- Declaring and assigning values to variables.
- Understanding fundamental Python data types: int, float, str, and bool.
- Checking variable data types using the type() function.
- Performing arithmetic operations using variables.
- Combining variables to calculate values, such as summing integers.
- Using variables to represent real-world data, such as names, ages, and quantities.
- Displaying multiple variables and calculation results in a single output.

## Function and parameter

Topics covered:

- Built-in functions: print(), input(), int(), float(), and round().
- Function calls and nested function calls.
- Type conversion from str to int and float.
- Mathematical operations: addition, division, and rounding numbers.
- Number formatting using thousands separators and decimal precision.
- String manipulation using strip(), title(), and split().
- Defining functions using def, with and without parameters.
- Understanding parameters, arguments, and default parameter values.
- Returning values from functions using return.
- Using the main() function to organize program execution.
- Using positional and keyword arguments in the print() function, including sep and end.
