# Python Learning Journey

Documenting my journey to becoming a software engineer through Python fundamentals, problem-solving, clean code, and progressively challenging projects.

# Week 1

## variabel data types

Topics covered:

- Printing output using the print() function.
- Understanding variables as containers for storing values in a program.
- Declaring and assigning values to variables.
- Understanding fundamental Python data types: int, float, str, and bool.
- Checking variable data types using the type() function.
- Performing arithmetic operations using variables.
- Combining variables to calculate values, such as summing integers.
- Using variables to represent real-world data, such as names, ages, and quantities.
- Displaying multiple variables and calculation results in a single output.

## Function and parameter

Topics covered:

- Built-in functions: print(), input(), int(), float(), and round().
- Function calls and nested function calls.
- Type conversion from str to int and float.
- Mathematical operations: addition, division, and rounding numbers.
- Number formatting using thousands separators and decimal precision.
- String manipulation using strip(), title(), and split().
- Defining functions using def, with and without parameters.
- Understanding parameters, arguments, and default parameter values.
- Returning values from functions using return.
- Using the main() function to organize program execution.
- Using positional and keyword arguments in the print() function, including sep and end.

# Week 2

## Conditionals and Operators

Topics covered:

- Using conditional statements: `if`, `elif`, and `else`.
- Evaluating conditions to control program execution.
- Comparing values using comparison operators: `==`, `!=`, `<`, `>`, `<=`, and `>=`.
- Using chained comparisons to evaluate ranges, such as `90 <= score <= 100`.
- Simplifying conditional logic by ordering comparison thresholds.
- Comparing strings using equality operators.
- Normalizing user input using `strip()` and `lower()`.
- Checking string prefixes using `startswith()`.
- Combining conditions using logical operators: `and` and `or`.
- Using the modulo operator (`%`) to determine whether a number is even or odd.
- Defining functions that return Boolean values (`True` or `False`).
- Using Boolean-returning functions to simplify conditional statements.
- Implementing grade classification based on score ranges.
- Comparing values and handling equal, greater-than, and less-than cases.

## Loops

Topics covered:

- Understanding `for` loops and `while` loops.
- Iterating over sequences and collections using `for`.
- Using `range()` to generate sequences of numbers for iteration.
- Using `_` as a loop variable when the iteration value is not needed.
- Controlling loop execution using `break` and `continue`.
- Using `while` loops for counting up and counting down.
- Updating counter variables using assignment operators, including `+=`.
- Understanding the relationship between loops and functions.
- Using string multiplication to repeat characters and strings.
- Creating vertical columns and horizontal rows using loops and functions.
- Printing square patterns using nested loops.
- Generating patterns using string multiplication and loops.
- Reusing functions to improve code organization and reduce duplication.
- Accessing list elements using indexing.
- Iterating over lists directly and accessing elements using their indexes.
- Using `range()` and `len()` to iterate over list indexes.
- Accessing dictionary values using keys.
- Iterating over dictionaries to access keys and corresponding values.
- Iterating over a list of dictionaries and accessing individual fields.
- Combining loops, functions, lists, dictionaries, and string operations in practical examples.
